# 🔥 发疯文学生成器

> **不是我想发疯，是这个世界逼我的。** 一键生成发疯文案，配图直接发朋友圈。

[**🔗 在线使用（手机直接玩）**](https://tomlen.gitee.io/fafa-generator/)

---

## 中文

今天上班想骂人？上早八想逃跑？恋爱让你心累？钱包空空如也？

选一个场景，选一个疯狂等级——工具帮你生成一条完美的发疯文案，配上精美卡片，你只需要复制粘贴发出去。

### ✨ 亮点

- 💼 **6 大场景**——上班、上学、恋爱、没钱、减肥、通用，总有一款戳中你
- 😤 **3 级疯狂**——微疯（保持微笑）、中疯（原地转圈）、癫狂（原地升天）
- 📋 **一键复制**——生成后直接粘贴到朋友圈/微博/群聊
- 🎴 **精美卡片**——暗黑系设计，保存图片发出去，比纯文字炸多了
- 🔒 **纯本地运行**——不需要登录，不上传数据

### 🎮 怎么玩

1. 选一个让你疯的场景（比如"上班"）
2. 选一个疯狂等级（推荐"癫狂"）
3. 点「开始发疯」→ 生成文案
4. 不满意？点「再疯一句」换一条
5. 满意了？复制或生成卡片发出去

## English

Didn't choose to go crazy — the world forced you. Select a scenario, pick your madness level, and generate the perfect unhinged text with a stunning card.

### ✨ Features

- 💼 **6 scenarios** — Work, School, Love, Broke, Diet, General
- 😤 **3 madness levels** — Mild, Medium, Full Breakdown
- 📋 **One-tap copy** — paste straight into your social media
- 🎴 **Dark aesthetic card** — save and share as image
- 🔒 **100% local** — no login, no data upload

---

## 🛠 Tech

Single HTML file. Pure vanilla JS. Text generation via curated template pool with random element injection.
